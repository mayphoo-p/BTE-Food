# BTE-Food Management System
Developed a Java-based desktop application using Java Swing to manage food court voucher records and generate sales reports. The system allows users to view voucher details, including food items, quantities, prices, and total amounts. It also provides food sales reports and time-slot-based reports with date filtering and ascending/descending sorting. JSON files are used to store and retrieve food, voucher, and time-slot data.

Technologies: Java, Java Swing, JSON, Gson, JDatePicker
